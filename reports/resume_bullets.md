# Resume bullets — implemented synthetic portfolio project

- Built a reproducible Python/PostgreSQL pipeline for a synthetic driver-reactivation experiment: 8,866 assignments, 12,626 ride events, validated ETL and driver-level analytical marts.
- Planned a two-sided A/B test with 80% power and a 2 pp MDE; implemented intention-to-treat analysis, a pooled proportion test, Newcombe confidence intervals and allocation-integrity checks.
- Developed SQL analytics using CTEs, LEFT/INNER JOINs, conditional aggregation, FILTER and window functions, preserving zero-activity drivers and preventing ride/payment join fan-out.
- Evaluated simulated unit economics: +2.89 pp reactivation uplift but −76.5k RUB-equivalent net incremental contribution; recommended against rollout under the stated assumptions.
- Created an interactive Streamlit/Plotly dashboard, DataLens-ready CSV marts and an executed Jupyter analysis; verified the workflow with 34 automated tests, including real PostgreSQL integration fixtures.

These bullets describe a synthetic portfolio study, not work on production users. Do not present the estimated effect as a business achievement at a real employer.
